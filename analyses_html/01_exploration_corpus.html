01 — Explorer et contrôler le corpus¶

Objectif : comprendre ce qui est disponible avant toute conclusion thématique. Le corpus actuel est un pilote de septembre 2015 ; il ne représente pas tout le pontificat.

Exécuter les cellules dans l'ordre avec le noyau Python du projet. Installation : pip install -r requirements.txt depuis la racine. Aucun téléchargement n'est déclenché par ce notebook.

from pathlib import Path
import json
import re
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from IPython.display import display

ROOT = next((p for p in [Path.cwd(), *Path.cwd().parents]
             if (p / "telecharger_discours.py").exists()), None)
if ROOT is None:
    raise FileNotFoundError("Ouvrir ce notebook depuis le dossier du projet.")
CORPUS = ROOT / "corpus_francois" / "corpus_nlp.jsonl"
if not CORPUS.exists():
    raise FileNotFoundError("Exécuter telecharger_discours.py puis preparer_corpus.py ; voir README.")
LANGUE = "fr"
df_all = pd.read_json(CORPUS, lines=True)
df = df_all.loc[df_all["language"].eq(LANGUE)].copy()
if df.empty:
    raise ValueError(f"Aucun document en {LANGUE}.")
if df.duplicated(["event_id", "language"]).any():
    raise ValueError("Doublons événement/langue : examiner le corpus avant l'analyse.")
df["date"] = pd.to_datetime(df["date"], errors="coerce")
df["text"] = df["text"].fillna("")
df["venue_raw"] = df["venue_raw"].fillna("")
df["n_mots"] = df["text"].str.findall(r"\b[^\W\d_]+(?:[’'-][^\W\d_]+)*\b").str.len()
RESULTATS = ROOT / "resultats"
RESULTATS.mkdir(exist_ok=True)
plt.rcParams.update({"figure.figsize": (10, 5), "axes.spines.top": False,
                     "axes.spines.right": False, "axes.titlesize": 14})
print(f"{len(df)} versions {LANGUE} ; {df['event_id'].nunique()} documents distincts.")
print("Période :", df["date"].min(), "→", df["date"].max())

Couverture et qualité¶

Une traduction est une version du même document. Le tableau de couverture décrit les fichiers collectés, pas les langues réellement prononcées ni les traductions manquantes sur le site.

CORPS (début) :
 Chers frères prêtres,

Je suis heureux d’être avec vous en cette rencontre. Je remercie Juan Pablo pour ses paroles, de même que pour son témoignage d’affection au nom des membres du Mouvement. Je conserve encore un vif souvenir de la rencontre de l’an dernier.

Le ve chapitre général que vous venez de célébrer a eu lieu pour le 50e anniversaire de la fondation de l’institut par le père Josef Kentenich. Et après ces années de chemin, vous avez à cœur de maintenir vivant le charisme fondateur et la capacité de savoir le transmettre aux plus jeunes. Il m’importe aussi qu’ils le maintiennent et le transmettent, de façon à ce qu’il continue à inspirer et à soutenir leur vie et leur mission. Vous savez qu’un charisme n’est pas une pièce de musée qui reste intacte dans une vitrine, pour être contemplée et rien de plus. La fidélité, le fait de garder le charisme pur, ne signifie en aucune façon de l’enfermer dans une bouteille scellée, comme si c’était de l’eau distillée, afin qu’il ne soit pas contaminé par l’extérieur. Non, le charisme ne se conserve pas en le mettant de côté, il faut l’ouvrir et le laisser sortir, afin qu’il entre en contact avec la réalité, avec les personnes, avec leurs inquiétudes et leurs problèmes. Et ainsi, dans cette rencontre féconde avec la réalité, le charisme croît, se renouvelle et la réalité se transforme aussi, se transfigure à travers la force spirituelle que ce charisme porte en lui.

Le père Kentenich l’exprimait très bien lorsqu’il disait qu’il fallait garder « l’oreille dans le cœur de Dieu et la main sur le pouls du temps ». Ce sont les deux piliers d’une authentique vie spirituelle. D’un côté, le contact avec Dieu . Il a la priorité, il nous a aimés en premier ; avant que quelque chose nous vienne à l’esprit, Il nous a déjà précédés avec son amour immense. Et saint Paul nous avertit de ne pas nous attribuer quoi que ce soit, comme si cela nous appartenait, car la capacité nous vient de Dieu (cf. 2 Co 3, 4-6). Aujourd’hui, dans l’Office divin, la lecture de saint Grégoire le Grand nous parlait du prêtre qui est placé comme phare au milieu du peuple, pour voir de loin tout ce qui s’approche (cf.
